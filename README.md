# Atelier Ambre ✨

> **Haute Parfumerie E-Commerce Platform & Executive Admin Workstation**

Atelier Ambre is a production-grade, luxury fragrance e-commerce web application. It features an editorial-style storefront, interactive scent discovery tools, seamless local payment gateway integration, and a dedicated executive command center for comprehensive store management.

## 🌟 Key Features

### 🛍️ Customer Storefront
* **Editorial Aesthetic:** High-end, glassmorphism design system with seamless Dark/Light theme toggling (Noir & Ivory with Gold accents).
* **Interactive Scent Finder:** A personalized quiz engine that recommends fragrances based on occasion, mood, and preferred olfactory notes.
* **Dynamic Product Catalog:** Features 50ml/100ml flacon sizing, dynamic pricing in BDT (৳), and an interactive Olfactory Pyramid (Top, Heart, Base notes) inspector.
* **Customer Dashboard:** Order tracking, saved addresses, scent match profiles, and a unified shopping wishlist.
* **Live Concierge Chat:** A floating, real-time widget for instant customer support.

### 💳 Payment & Checkout (Bangladesh Optimized)
* **SSLCommerz Integration:** Multi-channel gateway processing (bKash, Nagad, Visa, Mastercard).
* **Smart Delivery Logic:** Dynamic shipping cost calculation based on location (Inside Dhaka vs. Regional/Nationwide).
* **Auto-Generated Invoices:** Printable luxury order receipts with tracking capabilities.

### 🎛️ Executive Admin Workstation
* **Visual Analytics:** Real-time KPI dashboard tracking gross revenue, average order value (AOV), and regional sales distribution.
* **Inventory Command (CRUD):** Full control to add, edit, or delete fragrances, manage stock levels, and trigger low-stock alerts.
* **Fulfillment Desk:** Dedicated order tracking and status management (Pending -> Dispatched -> Delivered).
* **Campaigns & Bundles:** Create percentage-based flash discounts, promo codes, and curated discovery gift sets.
* **Concierge Hub:** Two-way synchronized chat to reply to customer inquiries instantly.

## 🛠️ Tech Stack

* **Frontend:** Next.js (App Router), React, Tailwind CSS, Framer Motion (Animations), Lucide-React (Icons).
* **State Management:** Zustand / React Context API.
* **Payment Gateway:** SSLCommerz API (Sandbox & Production ready).
* **Deployment target:** Vercel (Edge-optimized serverless architecture).
